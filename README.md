# HamLogger

HamLogger is a pnpm monorepo for a ham radio logging application.

## Packages

- `app`: React frontend powered by Vite.
- `server`: NestJS backend API.

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm test
```

Run individual packages with `pnpm dev:app` or `pnpm dev:server`.
